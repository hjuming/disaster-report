
# 花蓮馬太鞍溪洪災檢討報告網頁 - README

## 專案簡介

本專案為一份單頁式網頁報告，旨在將《花蓮馬太鞍溪洪災：系統性災害治理失靈剖析報告》的內容，以清晰、視覺化且易於閱讀的方式呈現。此網頁專為行動裝置優先瀏覽而設計，並採用響應式網頁設計（RWD），確保在各種螢幕尺寸上皆有最佳體驗。

## 功能特色

-   **響應式設計 (RWD)**：介面能自動適應手機、平板與桌上型電腦等不同裝置。
-   **視覺化封面**：以具衝擊力的主視覺與標題，迅速吸引讀者注意力，點出報告核心。
-   **互動式時間軸**：清晰呈現 9 月 23 日災難發生當天的關鍵時間點，幫助讀者快速理解事件序列。
-   **數據圖表化**：將傷亡人數、農業損失等關鍵數據，以易於理解的資訊圖卡呈現。
-   **結構化對比**：透過並排卡片與表格，清楚對照中央與地方政府在防災體系中的角色、困境與災後論述。
-   **深度剖析**：針對「垂直避難」爭議、風險溝通失敗、政治究責等核心議題，設有獨立的深度分析區塊。
-   **明確的改革建議**：將報告末尾的系統性改革建議，以條列式清單呈現，讓解決方案一目了然。

## 檔案結構

專案由單一 HTML 檔案構成，整合了所有內容、樣式與互動功能。

```
.
└── matianxi-disaster-report.html
```

## 如何預覽

直接使用任何現代網頁瀏覽器（如 Google Chrome, Firefox, Safari, Edge）開啟 `matianxi-disaster-report.html` 檔案即可。

## 技術棧

-   **HTML5**: 負責網頁的基礎結構與內容。
-   **Tailwind CSS**: 用於快速建構現代化、響應式的 UI 樣式。
-   **Google Fonts**: 提供更佳的網頁字體排版。

## 資料來源

本網頁報告的內容完全基於所提供的《花蓮堰塞湖災情檢討.pdf》研究文件進行綜整與改寫。所有資訊及圖片均來自新聞公開資料蒐集。
